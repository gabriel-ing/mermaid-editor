# Mermaid.js Graphical Editor

## Project Description
A web-based, graphical click-and-draggable editor for Mermaid.js flowcharts. The tool allows users to visually construct diagrams through a drag-and-drop interface and automatically generates the corresponding Mermaid.js code.

## Key Features
- **Visual Canvas**: A workspace where users can add, move, and arrange flowchart nodes.
- **Drag-and-Drop**: Easily position nodes and create connections visually.
- **Real-time Code Generation**: Instantly see the Mermaid.js syntax for the visual diagram.
- **Node Editing**: Modify text and types of nodes (e.g., rectangle, diamond, circle).
- **Connection Management**: Graphically link nodes to define flow and logic.
- **Export/Copy**: Easily retrieve the generated code for use in other documents.

## Personal Preferences & Principles
- **Keep it Simple**: Prioritize straightforward, readable code.
- **Minimal Abstraction**: Avoid hiding core logic behind deep layers of wrapper functions or complex design patterns unless absolutely necessary.
- **Readability First**: Ensure that anyone looking at the code can understand the flow and logic without jumping through multiple files.
- **Explicit Logic**: Prefer explicit implementations over "magic" or heavily automated frameworks that obscure how things work.
